## Description
Sample project that executes local rag over 1 document with LiteLLM + gemini 2.5 pro

## necessary dependencies (must run every time before deploying in virtual env):
```code
pip install google-adk llama-index-llms-litellm llama-index-embeddings-litellm llama-index-readers-file
pip install llama-index-embeddings-huggingface
```
